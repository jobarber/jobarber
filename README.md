### Justin Barber

Machine learning scientist in Denver. I build and evaluate transformer models, mostly for scoring
writing and speech, and work on generative models, post-training, and agent harnesses.

**Selected projects**

| | |
|---|---|
| [essay-scoring](https://github.com/jobarber/essay-scoring) | Multi-trait essay scoring with DeBERTa-v3 and ModernBERT on ELLIPSE, measured against human-human agreement, with subgroup and unseen-prompt checks. |
| [speech-proficiency-scoring](https://github.com/jobarber/speech-proficiency-scoring) | Explainable read-aloud scoring: Whisper timings, forced-alignment pronunciation scores, one model per construct, conformal intervals, feedback grounded in the model's own evidence. |
| [progan](https://github.com/jobarber/progan) | Progressive growing of GANs from scratch in PyTorch, trained to 128x128 on a laptop GPU. |
